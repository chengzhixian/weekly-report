# 周报配置与风格来源

本 skill 基于 [tang-t21/weekly-report](https://github.com/tang-t21/weekly-report) 改造，上游固定提交为 `ea0b0810485949311e4394f20f9a49ec7478e3af`，保留 MIT 许可证。

## 默认使用范围

从当前用户本机 Codex 的活动会话与归档会话提取指定时间段的工作记录，跨项目汇总。默认中文、Asia/Shanghai、最近七个自然日，输出 OKR 周报。

本版修正了按 UTC 划分日期、将旧会话的周外消息混入报告、助手答复只保留早期片段等问题，并增加最终答复提取、子代理排除、当前会话排除和截断披露。

## 报告风格

写法来自用户提供并已读取的个人周报和 OKR 周报样例，保留以下共性：

- 顶部列本期 O/KR，量化目标、当前结果和本周增量分开。
- 正文使用 Summary、本周计划与实际工作、下周计划。
- 工作内容和下一步都对齐 For O1 / For O2 等目标。
- 使用 [✔]、[❓]、[➕] 描述完成、待验证及计划外新增。
- 中文表述简洁，保留关键结果、必要指标、实际问题和验收边界。

本仓库不包含原始样例、个人姓名、飞书文档链接、文档 token、真实周报或本机对话记录。新使用者有正式 OKR 时优先沿用，没有则将归纳结果标为草案；不要继承他人的目标或完成数量。

详细写法见 [okr-style.md](okr-style.md)，原则直接写在 [SKILL.md](../SKILL.md)。
